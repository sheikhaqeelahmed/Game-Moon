# Third-party asset and licence register

Every third-party file that enters the repository or a build is listed here **before** it is used.
"In build" means the file ships to players.

| Asset | Source | Licence | Used for | In build |
|---|---|---|---|---|
| Unity packages (URP, Input System, etc.) | Unity Technologies | Unity Companion License | Engine packages | Yes |
| Rookie Scrapper reference (`docs/concept/refs/rookie.png`) | Client-supplied (Tripo AI / research figure) | Not verified | Concept reference only | No |
| SCRAP-BOT reference (`docs/concept/refs/scrap-bot.png`) | Client-supplied (IconScout) | Not verified | Concept reference only | No |
| Engineer Nova reference (`docs/concept/refs/nova.png`) | Client-supplied (Tripo AI) | Not verified | Concept reference only | No |
| Captain Bolt reference (`docs/concept/refs/captain-bolt.jpg`) | Client-supplied (Fab, "Space Explorer Bob") | Not verified | Concept reference only | No |
| Moon horizon photo (`docs/concept/refs/moon-horizon.jpg`) | Client-supplied, watermarked stock photo | Not licensed | Concept reference only | No |
| Moon surface photo (`docs/concept/refs/moon-surface.jpg`) | Client-supplied | Not verified | Concept reference only | No |

Reference images are kept out of the Git repository (it is public) and live only on the development PC.

All in-game textures (starfield, Halcyon, regolith, footprints) are generated by our own editor code,
and all sound effects are synthesised by `tools/generate_sfx.py`. The UI uses Unity's built-in LegacyRuntime font.
The texture code is in `Assets/Scripts/Editor/RustValleyGreyboxBuilder.cs`. All of this is original.
